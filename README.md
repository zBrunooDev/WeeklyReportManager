
# WeeklyReportManager

Projeto desenvolvido em C# para gerenciar relatórios semanais de atividades.

## Objetivo

Praticar conceitos de:

- Programação Orientada a Objetos (POO)
- Estruturas de dados
- Manipulação de listas
- Organização de projetos
- Git e GitHub

## Funcionalidades

- Cadastro de relatórios
- Listagem de relatórios
- Busca por período
- Edição de relatórios
- Exclusão de relatórios

## Tecnologias

- C#
- .NET
- Visual Studio
